# LIVE FIRE — prop library

Generated by `node tools/test/props.mjs --doc` from js/maps/props.js. Place a prop with `B.prop(type, x, y, z, opts)` inside a map's `build(B)`. Sizes are w x h x d in metres (x, up, z) of the default variant, measured from the geometry. Conventions, shared options and colliders: docs/ARCHITECTURE.md section 7 (Props). Rail top of a `track`: 0.39 m. Triangle counts are of the default variant (geometry is merged per material into the map chunks; identical heavy copies become thin instances by themselves).
